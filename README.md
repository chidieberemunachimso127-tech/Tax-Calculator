# Assignment Project
Personal Income Tax Calculator
This program calculates the United States federal personal income tax based on the user's filing status and taxable income.

## How to Run
1. Make sure Python is installed on your computer.
2. Open the terminal or command prompt.
3. Navigate to the folder containing the file.
4. Run the command: python tax_calculator.py

The program will prompt you to enter your filing status and taxable income, then calculate your total tax.
